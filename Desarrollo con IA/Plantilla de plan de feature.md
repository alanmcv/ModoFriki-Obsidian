# Plantilla de plan de feature

`docs/features/TEMPLATE.md`: estructura obligatoria de cada plan.

Secciones: objetivo · estado actual (verificado en el código) · alcance (dentro / fuera) · API · pipeline de middlewares · persistencia · contratos compartidos (firmas TypeScript) · tareas por rol con archivos y criterios de aceptación · plan de pruebas · riesgos · integración.

Planes existentes: `base`, `auth`, `community`, `works-chapters`, `user-reading`, `latest-chapters`, `popular`, `recommended`, y la propuesta `MODELO_DATOS_PROPUESTO`.

Los planes son una fuente para las [[Decisiones - Mapa|decisiones]] del proyecto.

Lo usa: [[Agente planner]] · Mapa: [[Desarrollo con IA - Mapa]]
