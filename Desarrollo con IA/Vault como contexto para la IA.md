# Vault como contexto para la IA

Este vault de Obsidian también es contexto para la IA.

- Su `CLAUDE.md` describe el proyecto, los repos, la estructura del vault, las etiquetas y la forma de trabajar.
- Las notas enlazadas permiten pedirle a Claude cosas como "implementa la [[Mejora - Health check real]]" y que encuentre el porqué, el dónde y el riesgo.
- Ventaja frente a los README: separa **qué es** (Dominio), **cómo está hecho** (Arquitectura), **por qué** (Decisiones) y **qué falta** (Mejoras).

Riesgo: si el vault queda desactualizado, engaña a la IA igual que un README viejo → [[Mejora - Documentación desactualizada]].
