# Glosario

| Término | Significado |
|---|---|
| **Manhwa** | Cómic coreano; suele leerse en scroll vertical (webtoon) |
| **Manga** | Cómic japonés; se lee por páginas, de derecha a izquierda |
| **Manhua** | Cómic chino |
| **Novela** | Novela ligera; en ModoFriki, por ahora, también se publica como imágenes |
| **Webcomic / webtoon** | Cómic pensado para leerse en pantalla, por capítulos |
| **Obra** | Una serie completa → [[Obra]] |
| **Capítulo** | Una entrega de la obra → [[Capítulo]] |
| **Capítulo extra / anuncio** | Tipos especiales de capítulo (EXTRA, ANNOUNCEMENT) |
| **Slug** | Nombre de la obra apto para URL (`mi-obra`) |
| **Borrador** | Contenido no publicado (DRAFT) → [[Estados de publicación]] |
| **Banner incap** | Imagen inicial que comparten todos los capítulos de una obra (significado exacto pendiente de confirmar) |
| **Lector en cascada** | Todas las páginas una debajo de otra |
| **Racha** | Días seguidos leyendo → [[Rachas y calendario de lectura]] |
| **Scanlation** | Traducción no oficial de cómics de terceros. ModoFriki **no** la usa: trabaja con autores independientes ([[Riesgos legales y de contenido]]) |
| **Autor independiente** | Creador que publica su propia obra sin editorial → [[Segmentos de clientes]] |
