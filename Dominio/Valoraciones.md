# Valoraciones

Puntuación de una obra de **0 a 5 en pasos de 0,5** (se guarda como medias estrellas, 0 a 10).

- Una por usuario y obra; se puede cambiar o quitar.
- Cero es válido.
- Sin valoraciones, el promedio es `null`.
